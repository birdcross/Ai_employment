# 제출 증빙 자료 체크리스트

아래 스크린샷을 이 폴더에 저장합니다.

## 필수

1. `01-desktop-home.png`
   - Vercel 배포 URL이 주소창에 보이도록
   - 데스크톱 HOME 화면 전체가 보이도록

2. `02-mobile.png`
   - Chrome 개발자도구의 모바일 화면 또는 실제 스마트폰 화면
   - 메뉴와 콘텐츠가 깨지지 않는 것이 보이도록

3. `03-ai-input.png`
   - AI MATCH 화면에 사용자 입력값이 채워진 상태

4. `04-ai-result.png`
   - AI 추천 TOP 3 또는 추천 결과와 분석 상세가 보이도록
   - 가능하면 주소창의 Vercel URL도 함께 표시

5. `05-ai-coding-tool.png`
   - ChatGPT/Claude/Copilot 등 AI 코딩 도구와 코드를 생성·수정한 대화 화면

## 권장

6. `06-github-repository.png`
   - GitHub 저장소의 파일 목록과 커밋이 보이도록

7. `07-vercel-deployment.png`
   - Vercel Production Deployment가 성공한 화면

8. `08-error-handling.png`
   - 필수값을 비우고 AI 추천을 눌렀을 때 안내 메시지가 나오는 화면

## 제출 전 확인

- API 키나 `.env` 내용이 스크린샷에 노출되지 않았는지 확인
- 이름/개인정보 등 제출에 불필요한 민감정보가 보이지 않는지 확인
- README에 실제 GitHub URL과 Vercel URL을 입력했는지 확인
